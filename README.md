# Steam Machine HDR Flicker Fix
> **Kudos to [beaglemoo](https://github.com/beaglemoo)**, whose [steam-machine-hdmi21](https://github.com/beaglemoo/steam-machine-hdmi21) patch made HDMI 2.1 and 4K 120Hz possible on the Steam Machine. The HDR Flicker Fix is a follow-up to that work, for TVs that flicker at 4K 120Hz with HDR on.

What it does: Stops flicker and "No signal" with HDR at 4K 120Hz.
Tested on a TCL 65Q750G.
