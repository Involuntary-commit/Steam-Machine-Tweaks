# Steam Machine Tweaks

Simple fixes and add-ons for the Valve Steam Machine. Each one installs with a single copied line and a short menu. No coding needed.

| Tweak | What it does |
|---|---|
| [HDR Flicker Fix](hdr-10bit-fix/) | Stops flicker and "No signal" with HDR at 4K 120Hz. Tested on a TCL 65Q750G. |

Open a tweak above for its step-by-step guide.
